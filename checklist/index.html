出行清单

一家三口 · 6岁女童 · 9/30-10/4 桐庐自驾
✅ 建议打印此页，出发前逐项打钩；重点物品用 🔴 标出。

📄 证件

  • 🔴 身份证（大人）
  • 🔴 儿童户口本/出生证明（住店用）
  • 驾驶证
  • 行驶证
  • 酒店预订确认短信

👕 衣物

  • 🔴 换洗衣物 4-5 套（含内衣）
  • 🔴 泳衣、泳帽、泳镜
  • 🔴 溯溪鞋/防滑凉鞋
  • 拖鞋（酒店+沙滩）
  • 防晒衣/薄外套（山区早晚凉）
  • 睡衣
  • 雨衣/雨伞

💦 玩水装备

  • 🔴 游泳圈（酒店有免费，可自带）
  • 🔴 水枪
  • 🔴 捞鱼网 + 小水桶
  • 🔴 防水袋（装手机）
  • 🔴 速干毛巾 2-3 条
  • 泳后换洗衣物袋

🌞 防护用品

  • 🔴 防晒霜/防晒喷雾
  • 🔴 驱蚊液 + 止痒膏
  • 🔴 遮阳帽
  • 太阳镜
  • 免洗洗手液

💊 药品

  • 🔴 退烧药（美林/泰诺林）
  • 🔴 肠胃药
  • 🔴 创可贴 + 碘伏棉签
  • 消毒湿巾
  • 晕车药
  • 体温计

📱 电子设备

  • 🔴 手机 + 充电器
  • 🔴 充电宝
  • 相机/GoPro
  • 车载充电线
  • 小度语音（民宿有）

🧸 儿童用品

  • 🔴 安抚玩具/小枕头
  • 🔴 零食 + 保温杯
  • 儿童餐具
  • 绘本/iPad（车上用）
  • 湿巾、纸巾

🚗 车上用品

  • 🔴 颈枕 + 小毯子
  • 🔴 垃圾袋
  • 车载导航支架
  • 墨镜
  • 零食饮料箱

最后检查项

  • 关好家中门窗、水电、燃气。
  • 给植物浇水，收好阳台衣物。
  • 确认油箱加满，ETC 余额充足。
  • 下载离线地图（山区信号可能不稳）。
  • 告诉家人出行计划和酒店地址。
